# Google TypeScript Style Guide Summary

This document summarizes key style rules for TypeScript frontend code in Resume Maker.

## 1. TypeScript Rules
- **Explicit Types**: Declare explicit types for API response schemas, props, and state values. Avoid using `any` unless absolutely necessary.
- **Imports**: Group imports (React core, UI components, types/API helpers).
- **Naming**: `PascalCase` for React component files and components (`ScreeningPanel.tsx`), `camelCase` for functions and variables.
- **Formatting**: Use 2 spaces for indentation in TSX/CSS.
